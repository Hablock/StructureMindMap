    Shortcuts

    Adding and editing

    TabAdd a child to the selected node EnterAdd a sibling (or finish editing) Click a selected nodeEdit text with the cursor where you clicked Double-click / F2Edit with all text selected; typing also starts editing Alt/Option+Enter, Shift+EnterLine break while editing Del / BackspaceDelete the selected nodes and their children

    Selecting and moving

    Shift+click, drag on canvasSelect several nodes Arrow keysMove between nodes SpaceCollapse or expand the selected branch Drag onto a nodeMake it a child; drop between two siblings to insert it there

    Clipboard and history

    Ctrl/Cmd+C, X, VCopy, cut and paste as nested lists Ctrl/Cmd+ZUndo; add Shift to redo

    View

    ScrollPan up and down; Shift+scroll pans sideways Right-button or middle-button dragPan the map Ctrl/Cmd+scroll, pinchZoom Shift+1 / Shift+2Fit map / center map Layout buttons, TidyNodes stay put until you ask: a layout button re-arranges the whole map, Tidy the selected branch

    Tools

    ChecklistTurn on with the toolbar button; click a box (with several nodes selected, it ticks them all) or press Ctrl/Cmd+Enter.
